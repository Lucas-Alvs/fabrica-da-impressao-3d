# Fábrica Da Impressão 3D

Sistema web para orçamentos de impressão 3D.

## Tecnologias

Next.js · TypeScript · TailwindCSS · PostgreSQL (ou SQLite em desenvolvimento)

## Rodando localmente

```bash
npm install
npm run dev
```

Crie o arquivo `.env.local` a partir do `.env.example` antes de iniciar.

## Publicação

Deploy na Vercel com um banco PostgreSQL (por exemplo, Neon). As variáveis
de ambiente necessárias estão listadas no `.env.example`.
